# 無白(むはく)— コンセプト仕様書 v1

> いまも、一粒ずつ落ちている。

## これは何か

人生の残り時間を直視させる、**入力ゼロの瞑想的メメント・モリ・アプリ**。

人生全体が「砂・粒子」として表現され、今この瞬間もリアルタイムに粒が落ち続けている。
「今この1秒」から「人生全体」まで、地図のように無段階の連続ズームで行き来できる。

## 決定事項(ユーザーとの対話 4 ラウンドで確定)

| 項目 | 決定 |
|---|---|
| 名前 | 無白(むはく / MUHAKU) |
| 核体験 | 秒→日→年→一生を連続ズームで眺める。砂は実時間で落ち続ける |
| 感情の方向 | 残り時間を直視する静かな緊張感(メメント・モリ) |
| 関わり方 | 入力ゼロ。眺めるだけで気づける |
| 数字 | 「いま人生の◯◯.◯◯◯◯◯◯◯%地点」が実時間で増え続ける |
| 終点 | 寿命は自分で設定(いつでも決めなおせる) |
| やりたいこと | 初回のみ登録し、時間軸上のマーカーとして置く |
| 世界観 | 現実の時間帯(朝・昼・夕・夜)と連動して変化 |
| 音 | 環境音あり(ミュート可) |
| 初回 | 暗転から始まる儀式的なオンボーディング |
| プラットフォーム | まず PC(デスクトップブラウザ)。スマホ/PWA は後続 |
| データ | 端末内のみ保存(localStorage)。アカウント不要 |

## ユーザーの課題(本人談)

- スマホでだらだらして時間を溶かす
- やりたいことの先延ばし
- 時間の大切さ・流れ方を「見てすぐわかる」形で意識したい

## デザイン方向性(3案・モック作成済み)

デザインモック: https://claude.ai/code/artifact/9b0f77b4-0a79-484c-90bc-8776648500c5

### 案A 余白の庭 — 墨と白砂(静謐・日本の余白)
枯山水。画面の大半は余白、右三分の一に一筋の砂。昼=紙に墨、夜=闇に白砂の図地反転。
数字は小さく正確に。ズームは「墨が解けて再び結ぶ」。

### 案B 砂の天体(シネマティック・崇高)
人生をひとつの天体として外から眺める。粒は星屑、過去は砂丘、未来は星雲、夢は氷青の恒星。
巨大な%カウンターが光の中に浮かぶ。ズームアウトで鳥肌を狙う。

### 案C 余命クロノメーター(デジタル・精密計器)
高級計器の文字盤。中央のゲージ管、ヘアラインの目盛り、tabular-nums のモノスペース数字。
「あなたの生は今も計測されている」という冷徹さ。

## マイクロコピー(確定稿・全案共通)

- タグライン: 「いまも、一粒ずつ落ちている。」ほか4案
- オンボーディング: 「あなたは、いつ始まりましたか。」→「終わりの日を、あなたが決めてください。」→「終わるまでに、何をしますか。」→「これが、あなたの時間になります。」
- 初回リビール: 「これが、あなたの一生です。——いまも、一粒。」
- ズームスケール名: この一秒 / 今日 / 今月 / 今年 / 一生

## 実装ロードマップ

1. デザイン方向性の決定(ユーザー選択待ち)
2. 「この一秒」メイン画面(Canvas パーティクル + 実時間%カウンター)
3. 連続ズーム(ホイール/ピンチ、LOD 遷移)
4. 儀式的オンボーディング + localStorage 保存
5. 環境音(Web Audio)+ 時間帯連動パレット
6. スマホ最適化・PWA
