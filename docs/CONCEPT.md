# 無白(むはく)— コンセプト仕様書 v4

> こぼれた一粒は、もう戻らない。

## これは何か

人生の残り時間を直視させる、**入力ゼロの瞑想的メメント・モリ・アプリ**。

**中心メタファー(v4.3で確定)**: 宙に浮かぶ**透明な丸いガラス球**の中の砂=あなたの残り時間。
あくまでも「時間の可視化」——透明だから、残りの量がそのまま目で見える。
砂面の中心はすり鉢状に沈み、**球の底の中央から**今この瞬間も砂が抜け落ちている。
落ちる砂は塊になったりほどけたり、**まだらに散らばりながら**、床に届く前に光を失って消える。
どこにも積もらない。そして球は**密閉されている——増やすことはできず、失われていくだけ**。

**舞台(v4で確定)**: 抽象的な闇や宇宙ではなく、**ホテルの美しい中庭**。
漆喰の壁に暖かい光だまり、石の床、そして**宙に浮かぶ透明なガラス球**(v4.2の陶の椀 → v4.3でガラスに。吊りワイヤー案も比較中)。光の中を漂う塵。
現実の空気の中で、あなたの残り時間だけが静かに非現実なことをしている、という画。

**背景スタイル(v4.1・比較検討中)**: ユーザーの提案で「よりシンプルな白黒」を検討。モックで3案を切替比較できる。
1. 中庭(現実の空気ごと描く)
2. 白黒(完全モノクロの禁欲。夢のリングだけ琥珀)
3. 白黒+金の砂(舞台はモノクロ、砂だけが色を持つ——「世界で唯一の色が、あなたの残り時間」)

- カウンターは **「残り 65.78140…% が減り続ける」**(増える数字ではなく減る数字)
- 消えた砂は最遠ズームでだけ、床の光の中の淡い霧として見える(取り戻せない過去)
- やりたいことはガラスに刻まれた**琥珀の緯線**。砂面が沈んでその線に達した日がその年齢。砂面との距離=残り時間が目で測れる
- 「この一秒(一粒が抜ける)」→「一生(中庭の全景)」まで無段階の連続ズーム

> 変遷: v2「落ちて積もる」→ v3「縁から溢れる(抽象の闇)」→ v4「中庭の水盤・中央から抜ける・まだらな落下」。
> いずれもユーザーの指示による転回。v3の課題「グラフィックの現実感不足」をv4の舞台設定で解決する。

## 決定事項(ユーザーとの対話 4 ラウンドで確定)

| 項目 | 決定 |
|---|---|
| 名前 | 無白(むはく / MUHAKU) |
| 核体験 | 水盤の砂が真ん中から抜けて消えるのを、秒→日→年→一生の連続ズームで眺める |
| 感情の方向 | 残り時間を直視する静かな緊張感(メメント・モリ) |
| 関わり方 | 入力ゼロ。眺めるだけで気づける |
| 数字 | 「残り ◯◯.◯◯◯◯◯◯◯%」が実時間で減り続ける |
| 終点 | 寿命は自分で設定(いつでも決めなおせる) |
| やりたいこと | 初回のみ登録。器の深さに刻まれた琥珀のリングになる |
| 世界観 | ホテルの美しい中庭の現実感(漆喰・石・暖かい光)。時間帯で光が移ろう |
| 音 | 環境音あり(ミュート可) |
| 初回 | 暗転から始まる儀式的なオンボーディング |
| プラットフォーム | まず PC(デスクトップブラウザ)。スマホ/PWA は後続 |
| データ | 端末内のみ保存(localStorage)。アカウント不要 |

## ユーザーの課題(本人談)

- やりたいことの先延ばし
- 時間の大切さ・流れ方を「見てすぐわかる」形で意識したい

## デザイン方向性 — 決定: A × B「余白の庭、光の砂」

デザインモック(決定稿のライブプレビューあり): https://claude.ai/code/artifact/9b0f77b4-0a79-484c-90bc-8776648500c5

**構図と静けさは案A、グラフィックの強度は案B。**

- Aから: 右三分の一の砂と広い「間」の構図 / 小さく正確な%カウンター / 縦書き明朝ラベル / 砂紋の堆積 / 非操作時のUI消灯 / 昼=紙に墨・夜=闇に白砂の図地反転
- Bから: 加算合成で発光する粒とブルーム / 落下の尾と着地の光の飛沫 / ズーム時の「露出の呼吸」 / 低いドローン+深いパルスの音 / 初回の「流星→引きのカメラ」演出
- 夜パレット(主戦場): bg `#0A0C11→#151820` / 粒 `#EBDCB2` / 堆積 `#3B4048` / 強調 `#D8A868` / 文字 `#E9E3D5` / 淡 `#94908A`

### 検討した3案(記録)

#### 案A 余白の庭 — 墨と白砂(静謐・日本の余白)
枯山水。画面の大半は余白、右三分の一に一筋の砂。昼=紙に墨、夜=闇に白砂の図地反転。
数字は小さく正確に。ズームは「墨が解けて再び結ぶ」。

#### 案B 砂の天体(シネマティック・崇高)
人生をひとつの天体として外から眺める。粒は星屑、過去は砂丘、未来は星雲、夢は氷青の恒星。
巨大な%カウンターが光の中に浮かぶ。ズームアウトで鳥肌を狙う。

#### 案C 余命クロノメーター(デジタル・精密計器)
高級計器の文字盤。中央のゲージ管、ヘアラインの目盛り、tabular-nums のモノスペース数字。
「あなたの生は今も計測されている」という冷徹さ。

## マイクロコピー(v3 改稿)

- タグライン: 「こぼれた一粒は、もう戻らない。」「人生は、すこしずつ溢れている。」ほか
- オンボーディング: 「あなたは、いつ始まりましたか。」→「終わりの日を、あなたが決めてください。」→「終わるまでに、何をしますか。」→「これが、あなたの残りになります。」
- 初回リビール: 「これが、あなたの残りです。——いまも、一粒。」
- カウンター添え言葉: 「人生の残量」
- ズームスケール名: この一秒 / 今日 / 今月 / 今年 / 一生

## 儀式(初回オンボーディング・v4)

1. 暗闇。一粒が抜け落ち、光を失って消える
2. 「こぼれた一粒は、もう戻らない。」
3. 生年月日 → 4. 寿命(暗い中庭に空の水盤が浮かび上がる)
5. 器に砂が満ちる(=一生の全量)。頂まで満ちて、一拍の静寂
6. **すでに生きた歳月ぶんが底から一気に抜け落ちて霧散する。残りだけが暖かい光の中に残る**(山場)
7. やりたいこと → 器の深さに琥珀のリングが刻まれる
8. 一粒が抜け落ち、カウンター点灯「これが、あなたの残りです。」

## グラフィック忠実度についての合意

- モック(v2〜v4)は **Canvas 2D のスケッチ**であり、グラフィックは未着手に等しい(ユーザーにも明示済み)
- 本実装は **WebGL**(数万粒のパーティクル、被写界深度、ブルーム、柔らかい影)で「ホテルの中庭」の現実感まで引き上げる
- モックで確認するのは構図・光の方向・砂の振る舞い(まだらな落下)のみ
